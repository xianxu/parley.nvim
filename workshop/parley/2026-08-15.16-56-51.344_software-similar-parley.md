💬: tell me what are the similar software to parley?

🤖:[ToolFable*]

Based on what we saw in the repo earlier, Parley's core identity is a **markdown-buffer chat client** for Neovim — the conversation *is* a plain markdown file. That's the axis to compare along.

### Closest relatives (chat lives in a markdown buffer)

- **gp.nvim (Robitx)** — Parley's direct ancestor; Parley is a fork that stripped the inline text-manipulation commands to focus on chat. Same chat-file format, same streaming architecture. It's still one of the mainstream picks, described as "ChatGPT sessions & instructable text" for Neovim.
- **sllm.nvim** — very similar philosophy: in-editor chat powered by Simon Willison's LLM CLI, streaming replies into a Markdown buffer with rich context (files, URLs, selections, diagnostics). The context-injection features overlap with Parley's `@file`/annotation mechanisms.
- **flyboy** — simple ChatGPT interaction in a Markdown buffer, supporting GPT-4 and Azure OpenAI; a minimal take on the same idea.
- **gptel (Emacs)** — probably the closest cross-editor analog: buffer-as-conversation, plain-text transcripts, multi-provider. If you want to understand Parley's design space, gptel is the Emacs counterpart.

### Same category, heavier UI

- **ChatGPT.nvim (jackMort)** — popup/panel UI rather than plain buffers; commonly listed alongside gp.nvim in plugin roundups.
- **CopilotChat.nvim** — a chat interface for GitHub Copilot for asking coding-related questions directly; tied to Copilot as backend.
- **Kurama622/llm.nvim** — interact with any LLM (GPT, GLM, Kimi, DeepSeek, Gemini, Qwen, or local via ollama) and define your own AI tools per model.

### Different category: agentic code assistants

These do much more than chat (editing code, applying diffs, multi-step tasks) — a deliberate non-goal for Parley:

- **avante.nvim** — "chat with your code as if you are in Cursor AI IDE"; supports code generation, inline refactoring, and interactive chat, and is highly adopted in AI workflows.
- **codecompanion.nvim** — a Copilot-Chat-like experience with an inline assistant, supporting Anthropic, Gemini, Ollama, and OpenAI; now built on the Agent Client Protocol (ACP) with multi-step task execution.
- **sidekick.nvim** — a newer, fast-growing "Neovim AI sidekick" supporting Claude and OpenAI.
- Outside Neovim: **aider**, **Claude Code**, **Cursor** — terminal/IDE agents, not conversation-file tools.

### Where Parley is distinctive

Likely its strongest differentiators versus all of the above: conversations as durable, greppable markdown files under your own directory structure (chat history as a knowledge base), the summary-line convention for scanning, and deliberate minimalism — no code-editing agent features. Most competitors treat chat as ephemeral UI; Parley treats it as documents.
