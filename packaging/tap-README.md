# Parley Homebrew tap

A chat notebook for macOS, with an isolated Neovim profile.

```sh
brew install xianxu/parley/parley
parley
```

Follow the welcome chat to connect a provider account and choose a model.
Your existing Neovim configuration stays separate.

[Installation, updates and removal](https://github.com/xianxu/parley.nvim/blob/main/packaging/README.md)

The formula is generated from an immutable
[Parley release](https://github.com/xianxu/parley.nvim/releases) and its dependency
registry. Maintainers update it with `scripts/release-parley.sh` in the source
repository. Please report product problems in
[Parley issues](https://github.com/xianxu/parley.nvim/issues).
